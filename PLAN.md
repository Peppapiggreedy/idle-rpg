Лёгкий рабочий документ. Обновляется по мере продвижения: чеклист дорожной карты

## Сеттинг

Рабочее название: **Idle RPG**. Валюта: **золото**. Первая зона: **Пастуший луг**.
Первый класс: **Воин**.

Правило: механики и жанровые тропы классических MMORPG заимствуем свободно,
названия/лор/арт — только оригинальные (см. CLAUDE.md про запрет IP Blizzard).

## Core loop

Авто-бой с мобом → моб умирает → золото + опыт (+ иногда лут) → покупаем апгрейды
урона → убиваем быстрее → открываем зону посильнее. Поверх — уровни, лут по тирам
редкости, экипировка.

## Структуры данных

Все игровые числа — `Decimal` из break_infinity.js. В JSON-сейве `Decimal`
сериализуется строкой. `version` и `lastTimestamp` — служебные числа, им `Decimal`
не нужен.

```ts
interface Character {
  level: Decimal
  currentXp: Decimal
  xpToNext: Decimal
  baseDamage: Decimal
  gold: Decimal
}

interface Monster {
  id: string
  name: string
  maxHp: Decimal
  currentHp: Decimal
  goldReward: Decimal
  xpReward: Decimal
}

type Rarity = 'common' | 'uncommon' | 'rare' | 'epic' | 'legendary'

interface Item {
  id: string
  name: string
  rarity: Rarity
  statBonus: Decimal
}

interface Zone {
  id: string
  name: string
  monsterPool: string[] // id мобов из src/lib/data
  unlockCost: Decimal
}

interface SaveData {
  version: number
  character: Character
  currentZoneId: string
  lastTimestamp: number // Date.now() последнего сохранения, для оффлайн-прогресса
  upgrades: Record<string, Decimal> // id апгрейда -> сколько куплено
}
```

## Формулы

- Стоимость апгрейда: `cost_next = cost_base * 1.15^owned` — каждая покупка дорожает
  на 15%, классическая экспонента incremental-жанра: урон догоняет цены, но не даром.
- Кривая опыта: `xpToNext = 10 * level^1.5` — степенная кривая: уровни замедляются
  с ростом, но никогда не встают колом.
- Оффлайн-прогресс: `elapsed = min(Date.now() - lastTimestamp, 8 часов)` — начисляем
  награду одним агрегатом (среднее золото/опыт в секунду × elapsed), не проигрывая
  тики по одному, чтобы загрузка была мгновенной при любом отсутствии.
