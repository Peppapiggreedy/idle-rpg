# PLAN.md — дизайн-документ и план разработки

Лёгкий рабочий документ. Обновляется по мере продвижения: чеклист дорожной карты
отмечаем сделанным в том же PR, где закрыт пункт.

## Сеттинг

Рабочее название: **Idle RPG**. Валюта: **золото**. Первая зона: **Пастуший луг**.
Классов два: **Страж** (мана с правилом задержки) и **Изувер** (ярость от боя).
Класс выбирается при новой игре и не меняется.

Правило: механики и жанровые тропы классических MMORPG заимствуем свободно,
названия/лор/арт — только оригинальные (см. CLAUDE.md про запрет IP Blizzard).

## Цель игры

**Игра КОНЕЧНА.** Победа — прохождение рейда на сотом уровне. Это не украшение
дизайн-документа, а решение, из которого следует остальное:

- **Потолок уровня — 100.** Дальше опыт не копится, полоска сменяется словами
  «максимальный уровень». Кривая опыта задаётся ТАБЛИЦЕЙ УБИЙСТВ на уровень,
  а не формулой: убийства умножаются на время боя и дают часы, а опыт — величина
  производная, в которой часов не видно.
- **Кривые стоимости сходятся.** У бесконечной игры цена обязана обгонять доход
  вечно; у конечной — сойтись к сотому уровню, иначе последняя треть окажется
  стеной, за которой ничего нет.
- **Тиры предметов ограничены.** Лучшая вещь в игре существует и достижима:
  без потолка «лучшее» всегда впереди, и рейд нечем было бы наградить.
- **Прогон баланса проверяет ПУТЬ ЦЕЛИКОМ.** Пока игра была бесконечной, мерить
  можно было только куски — час в такой-то зоне. У конечной есть длина, и она
  измеряется: 1..100 одним прогоном, 14–19 часов игрового времени.

Отсюда же лестница открытий: каждые десять уровней — новый данж и новая
механика, и это заменяет бесконечно растущие числа как повод играть дальше.
Работает она при двух условиях: лестница видна заранее, а названия будущих
ступеней скрыты.

## Core loop

Авто-бой с мобом → моб умирает → золото + опыт (+ иногда лут) → игрок сам
разбирает добычу и надевает апгрейды → убиваем быстрее → открываем зону
посильнее. Поверх — уровни, таланты, лут по тирам редкости, экипировка,
данжи и ремёсла.

## Структуры данных

Все игровые числа — `Decimal` из break_infinity.js. В JSON-сейве `Decimal`
сериализуется строкой. `version` и `lastTimestamp` — служебные числа, им `Decimal`
не нужен.

Точные типы живут в `src/lib/types/index.ts` и `src/lib/game/state.ts` — здесь
только опорные, которые задают форму мира. Прямых полей урона нет ни у героя,
ни у предмета: всё производное считает конвейер `game/stats.ts` из источников
(уровень, таланты, экипировка).

```ts
type Rarity = 'common' | 'uncommon' | 'rare' | 'epic' | 'legendary'

interface Item {
  id: string
  name: string
  rarity: Rarity
  slot: SlotId
  level: number // уровень моба, с которого упал: сила вещи растёт от него
  hands?: 1 | 2 // только у оружия
  mods: StatModifier[] // предмет действует ТОЛЬКО через конвейер статов
}

interface Zone {
  id: string
  name: string
  monsterLevelRange: { min: number; max: number }
  monsterPool: MonsterArchetype[] // роли, не готовые мобы
  rewardMultiplier: Decimal
  unlockRequirement: number // уровень персонажа
  isSafe: boolean
}
```

## Формулы

- Кривая опыта задаётся **таблицей убийств на уровень** (`KILLS_PER_LEVEL` в
  `data/balance.ts`) с линейной интерполяцией между опорными точками, а опыт
  считается из неё: `xpToNextLevel(L) = killsTarget(L) × ожидаемый опыт с моба
  подходящей зоны`. Так кривая привязана к реальной награде, а не к
  параллельному допущению, и в ней сразу видны ЧАСЫ. Ступеньки на 60 и 90
  уровнях намеренные: игра входит в новую треть.
- Сила предмета от уровня: `itemLevelScale(L) = 1 + 0.16 × (L − 1)` — та же
  прямая, что у HP мобов (`hpPerLevel`). Прямая против прямой: отношение сил
  внутри зоны почти постоянно, и коридор темпа 8–15 секунд держится по
  построению, а не подгонкой на каждую зону.
- Оффлайн-прогресс: `elapsed = min(Date.now() - lastTimestamp, 8 часов)` —
  награда одним агрегатом ШАГАМИ по минуте (набранные уровни меняют статы,
  а с ними и темп следующего шага), затем срез на `OFFLINE_EFFICIENCY`.
  Проигрывать тики по одному нельзя: загрузка должна быть мгновенной при
  любом отсутствии.
- Разрыв режимов — **цель баланса, а не множитель в коде**: ручная игра
  с зельями ≈ 1.5 × автокаст без зелий, оффлайн — 0.2 от автокаста.
  Разница авто и руки возникает естественно, из задержки реакции и того,
  что автокаст не придерживает кулдауны.

## Что сознательно НЕ делаем сейчас

Престиж, PvP, репутации, третий класс, журнал коллекций, мобильные сборки,
Steam, публичный плейтест. Уровней у профессий нет и не будет: это второй
счётчик, который надо гриндить, а гриндить в игре уже есть что.

Рейд из этого списка УШЁЛ: он и есть цель игры (см. «Цель игры») и делается
итерацией 6. Вынесен он туда намеренно — числа финального босса проектируются
от реального эндгейма, а реального эндгейма до итерации 5 не существовало.
Спроектировать его, не пройдя сотый уровень своими руками, — значит подогнать
под воображаемого героя.

## Единственная проверка, которую нельзя автоматизировать

Сорок минут живой игры подряд. Всё остальное держат тесты: коридор темпа,
разброс по уровням, интервал решений, доля времени на привалах, равенство
стилей и веток. Чего они не видят — скучно ли. За этим нужен человек,
и подменить его прогоном нельзя.
