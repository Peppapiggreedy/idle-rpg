# Проект: Idle RPG (рабочее название)

Браузерная idle/incremental RPG в духе Classic WoW, но со **всеми оригинальными
названиями**. Использовать IP Blizzard нельзя: никаких названий зон, мобов,
предметов, рас, классов из World of Warcraft — придумывай свои.

## Стек

- Vite + Svelte + TypeScript
- break_infinity.js (класс `Decimal`) — для всех игровых чисел (золото, урон, опыт, HP)
- Сохранение: localStorage, JSON, с версией формата
- Деплой: GitHub Actions → GitHub Pages (`base: '/idle-rpg/'` в vite.config.ts)

## Команды

- Установка: `npm ci`
- Дев-сервер: `npm run dev`
- Сборка: `npm run build`
- Проверка типов: `npm run check`

## Архитектура (папки)

- `src/lib/game/` — логика: game loop (тик), бой, формулы, сейв/загрузка
- `src/lib/ui/` — Svelte-компоненты
- `src/lib/data/` — статические данные (мобы, предметы, зоны)
- `src/lib/types/` — типы

## Правила разработки

- Все игровые числа — только через `Decimal` из break_infinity.js, не через обычный `number`.
- Логику игры держи отдельно от UI (в `src/lib/game`), чтобы её можно было тестировать.
- Формат сейва имеет поле `version`. При изменении структуры сейва — обязательно
  добавляй функцию миграции старых сейвов, не ломай прогресс игрока.
- Работай маленькими шагами. Один PR = одна фича.
- Коммить с понятными сообщениями в стиле Conventional Commits (`feat:`, `fix:`, `chore:`).
- Никогда не коммить секреты/ключи.

## Соглашения по коду

- TypeScript strict, осмысленные имена, короткие функции.
- Комментируй нетривиальные игровые формулы.
